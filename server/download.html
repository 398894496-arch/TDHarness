下载本机 Agent

正在识别系统…

在公司局域网里打开本页，下载后安装。浏览器提示「不是私密连接」是正常的（这是公司自己的服务器），点「高级」→「继续前往」即可。

下载 Windows 版

双击运行。它先让这台电脑加入公司的加密网络（Tailscale，Windows 问「是否允许更改」时点「是」），在家也能用；再从服务器下载程序装好，桌面和开始菜单各有一个 TDHarness 图标。用管理员发给你的账号登录。
提示「智能应用控制已阻止」时，这台电脑装不了未签名的程序，请联系管理员。

下载 macOS 版

双击下载的 TDHarness.dmg，在打开的窗口里把 TDHarness 拖到旁边的 Applications（应用程序）文件夹，就装好了。第一次打开时系统说「无法验证开发者」：到「系统设置 → 隐私与安全性」点「仍要打开」，以后就不用了。第一次打开还会请你加入公司的加密网络（Tailscale）：输一次这台 Mac 的开机密码，Tailscale 请你「允许」时点「允许」，在家也能用。用管理员发给你的账号登录。
