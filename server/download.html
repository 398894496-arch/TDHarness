下载本机 Agent

正在识别系统…

在公司局域网里打开本页，下载后安装。浏览器提示「不是私密连接」是正常的（这是公司自己的服务器），点「高级」→「继续前往」即可。

下载 Windows 版

双击运行，它会从这台服务器下载程序并装好，桌面和开始菜单各有一个 TDHarness 图标。用管理员发给你的账号登录。

下载 macOS 版

在「下载」里双击这个 zip（Safari 会自动解开），打开解出来的 TDHarness 文件夹，把 TDHarness 拖到旁边的「应用程序」上就装好了。第一次打开时系统说「无法验证开发者」：到「系统设置 → 隐私与安全性」点「仍要打开」，以后就不用了。用管理员发给你的账号登录。
