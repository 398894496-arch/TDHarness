# company-erpnext

公司的 ERPNext 装在公司服务器上，只在公司私网里能打开。下面的菜单名，都是从我们这台 ERPNext 的中文界面取的（ERPNext 16）。屏幕上看到的和这里不一样时，以屏幕为准，告诉用户实际看到的是什么；不确定的步骤不要编，让用户截图给你看。

## 打开和登录

- **从 TDH 打开（推荐）**：TDH 左栏「聊天」下面的「ERPNext」，点一下，浏览器会打开 ERPNext，并自动用他的 TDH 账号登录，不用输密码。这个入口要电脑端 2026.11.20.8 及以后才有。
- **直接打开**：浏览器打开 `https://tdharness.tail9c7cc7.ts.net`，在登录页点「TDH」，输入 TDH 的账号和密码。
- ERPNext 里的账号就是 TDH 账号，不用另外注册，也没有单独的密码；在 TDH 离职或停用后，ERPNext 也会自动停用。
- **打不开**：
  - 先确认电脑在公司网里：在公司就连公司网；不在公司，要打开 Tailscale 并确认已连上。
  - 还打不开，就找管理员。可能是这台设备还没被放行访问 ERPNext。
- **登录后显示英文**：系统默认已是中文。个别人显示英文，点右上角的头像，选「My Settings」，把「语言」改成「中文」，保存后刷新页面。

## 现在的状态和两家公司

- 设置已完成（2026-11-21），界面默认中文，币种人民币，会计年度按自然年。里面有两家公司：
  - **山东壹通达高分子材料有限公司**（简称 YTD）：主营公司，在龙口市，负责生产，给腾达供货。新建单据默认就是这家公司。
  - **烟台腾达聚氨酯有限公司**（简称 TD）：老客户不愿意换开票抬头，出口走腾达。
- 两家之间的供货关系已经登记好：
  - 在壹通达里，腾达是「内部客户」，壹通达卖给腾达就开给这个客户；
  - 在腾达里，壹通达是「内部供应商」，腾达向它下采购订单。
  - 开单时要先看清单据顶上的「公司」选的是哪一家，出口的单子一般选腾达。
- 物料、客户、供应商都还没录入，开单之前要先建好。
- ERPNext 里的数据，目前还没有和 TDH 里的财务对账、排产、日报连起来。那些数据仍然来自拖进 TDH 的表格，两边以后再同步。

## 怎么找菜单

- 左边是**工作区**：主页、销售、采购、库存、生产、会计、开票管理、付款、财务报表、客户关系等。
- 顶上的搜索框（「搜索或输入命令」）可以直接输入单据名，比如「销售订单」，回车就能打开列表。
- 每种单据都是一个列表：右上角「新建」开一张新的，填好以后点「保存」。

## 保存、提交、取消、修订（最重要的规矩）

- 「保存」：存成草稿，还能随便改。
- 「提交」：正式生效，比如出库会扣库存、发票会记账。提交以后不能直接改。
- 提交错了：先「取消」这张单，再点「修订」生成一张新的去改，改好后重新提交。不要另开一张重复的单子。

## 常用流程（中文菜单名）

- **基础资料**：
  - 物料（商品、原料、成品都叫「物料」）、物料组；
  - 客户、供应商；
  - 仓库；
  - 价格表、物料价格。
  - 开单之前，要先把这些建好。
- **销售**：报价 → 销售订单 → 销售出库（发货）→ 销售发票 → 收付款凭证（收款）。后一张单可以在前一张单上点「创建」直接生成，不用重新填物料。
- **采购**：物料需求（要买什么）→ 询价、供应商报价 → 采购订单 → 采购入库（收货）→ 采购发票 → 收付款凭证（付款）。
- **库存**：
  - 领料、调拨、报废这些库内移动，用「物料移动」；盘点后改账面数量，用「库存调账」。
  - 查库存看报表「库存余额(收发存汇总表)」，查每一笔进出看「物料凭证」。
- **生产**：物料清单（BOM，一个产品要用哪些料、各用多少）→ 生产计划 → 生产工单 → 生产任务单（工序）。领料和成品入库，在生产工单上操作。
- **财务**：
  - 收款、付款用「收付款凭证」，其他记账用「日记账凭证」。
  - 报表看「应收账款」「应付账款」「会计总账」，以及「财务报表」工作区。

## 权限

- 每个人的权限是按 TDH 的岗位先给的一份默认权限：
  - 管理员：全部；
  - 行政财务：财务、采购；
  - 销售：销售；
  - 生产设计：生产、库存；
  - 内勤：销售、库存；
  - 其他人：员工基本权限。
- 金额：单价、采购价、库存金额、订单金额，各岗位按自己的工作都能看。
- 应收账款、应付账款、利润表、毛利、总账、银行、收付款凭证这些财务信息，只有管理员和行政财务能看（用户 2026-11-21 定的）。
- 看不到某个菜单，或者提示「没有权限」，是权限问题，不是操作错了。请找管理员在 ERPNext 里调整。

## TDH 助手能做什么

- 能讲怎么操作、在哪个菜单、单据之间怎么衔接，也能帮着检查用户截图里的单子填得对不对。
- 现在还不能替用户在 ERPNext 里录单或查数，以后会接上。不要假装已经替他做了。
- 用户要改正式数据（提交、取消单据，改库存），提醒他先确认，提交以后就记账了。
